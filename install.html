🐾 Install SimplyKnown Kids

📱 Android tablet — real app install

⬇ Download APK (1.3 MB)
  1. Tap the download button above on your Android tablet.
  2. When it finishes, tap the downloaded file (or open Files → Downloads).
  3. Android may ask: "Allow installs from this source?" — say yes.
  4. Tap Install. Done.
  5. The app icon appears on your home screen — no browser bar, just the app.

The first launch may briefly show a Chrome screen while it verifies — that's expected, only happens once. After verification it always opens directly fullscreen.

🍎 iPad / iPhone

  1. Open this site (kids.simplyknown.co) in Safari.
  2. Tap the Share button (square with arrow).
  3. Scroll down → tap Add to Home Screen.
  4. Tap Add in the top-right.

iOS opens it as a Progressive Web App (PWA) without browser chrome. A real native APK isn't possible for iPhone without Apple Developer fees.
