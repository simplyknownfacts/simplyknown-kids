## What changed
1. Parent Settings now uses a stable cream/white utility page with dark readable text. It no longer inherits the child's animated sky or changes its palette when a child theme is selected.
2. One settings panel is visible at every width. A phone section picker and grouped desktop sidebar replace the long phone accordion stack. Overview leads with Activities, Animal companion, Voice and Children; less common settings sit under More settings. Theme is now reachable in desktop navigation.
3. A labeled Settings for dropdown defaults to the currently active child. Switching this selection does not change the child playing in the app. Per-child saves show whose settings changed; family/device controls are separate. Activities use labeled grouped switches; empty feature rows are omitted. Voice/theme choices are real keyboard-accessible buttons.
4. Add child is three short steps: name/birthday, companion, voice/Create. Opening it hides unrelated settings controls. Back retains choices; Cancel resets the draft. Companion and voice remain explicit required choices, birthdays are rechecked at final creation, and repeated Create clicks make one profile. Color and the optional paid name-voice offer sit under More options; paid names are unchecked by default.
5. The existing PIN/lockout, profile schema, feature age defaults, account/Yoto/YouTube controls and offline features are retained. New stylesheet `css/parent-settings.css` is included in service-worker cache **vb-v157**, including the required shell set.
