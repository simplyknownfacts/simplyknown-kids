## Deploy / workflow (important)
- Deploy = `git push origin HEAD:main`. GitHub Pages serves `origin/main`. Propagation ~1–2 min.
- **Bump the `vb-vNN` string at the top of `sw.js` on every change** — the service worker is network-first + cache-name-versioned; without a bump, devices keep stale assets. (The SW does NOT skipWaiting, so a device may need a second reload to pick up new sw.js logic; assets refresh network-first.)
- Local verification: the e2e `.mjs` import `playwright` the repo-standard way and need `npm install --prefix tests/e2e`. **This worktree has no node_modules** — I ran local checks by temporarily importing playwright by absolute path from a sibling worktree (`.claude/worktrees/reverent-spence-47072a/node_modules`), then reverting to the bare import before committing.
- Harmless: every commit prints `failed to delete .../worktrees/reverent-spence-47072a: Permission denied` (OneDrive lock on a stale worktree). Commits succeed.
