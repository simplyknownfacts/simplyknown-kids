## Decisions from the inventory

1. Keep all registered files in the first pass. Peek-a-boo needs an explicit navigation/retirement decision because the registry and file remain while the current menu hides it.
2. Keep Finger Paint and Color Splash for now, but treat their current blank-canvas duplication as the clearest consolidation or redesign candidate.
3. Do not present emoji color as controlled curriculum art until the four supported device/platform families have been checked; rendered emoji colors can differ from the lesson’s CSS color.
4. Essential questions use the shared `speakInstruction(text)` contract when available and retain `speak(text)` only as a compatibility fallback on this branch. Praise, names and “Try again” remain replaceable feedback.
5. Quiz rounds changed here accept one correct completion. Shape Match and Count Along carry the same requirement in the separate resilience pass.
