# Full E2E v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline, checkpointed) to implement this plan. Method B uses the Workflow tool. Steps use `- [ ]` checkboxes.

**Goal:** Run two independent, thorough E2E passes (scripted-assertion harness + agent-driven human-like) over the live `kids.simplyknown.co`, verifying behavioral *and* visual correctness across 8 tiers × 19 activities × phone+tablet, fixing critical bugs live and logging the rest.

**Architecture:** A data-driven Playwright harness (Method A) seeds a profile per tier via localStorage, drives real interactions, and asserts outcomes against an oracle, screenshotting each state. Then I visually review the gallery. Then a Workflow fans out one agent per tier (Method B) to re-test by eye. Findings are consolidated; criticals fixed live.

**Tech Stack:** Node + Playwright (already in `tests/e2e/`), the Workflow tool, the live GitHub-Pages site. Spec: `docs/superpowers/specs/2026-06-05-full-e2e-v2-design.md` (Appendix A = the oracle).

### Task 1.1: Harness scaffolding

**Files:** Create `tests/e2e/v2/run-e2e-v2.mjs` (orchestrator), `tests/e2e/v2/lib/harness.mjs` (helpers), `tests/e2e/v2/oracle/*.mjs` (per-section oracle data). Test target = live site (override with `BASE_URL`, default `https://kids.simplyknown.co`).

- [ ] **Step 1: Add the seeding + instrumentation helpers** in `lib/harness.mjs`:
  ```js
  export const TIERS = [1,2,3,4,5,6,7,8];
  // birthdays that land in each tier midpoint (months: 6,18,30,42,54,66,78,120)
  export const tierBirthday = (tier) => {
    const months = [6,18,30,42,54,66,78,120][tier-1];
    const d = new Date(2026,5,5); d.setMonth(d.getMonth()-months);
    return d.toISOString().slice(0,10);
  };
  // Seed a single profile at a given tier with optional feature flags, before app code runs.
  export async function seedProfile(context, {tier, features={}, coloringPages=[]}) {
    const profile = { id:'t'+tier, name:'Tier'+tier, birthday:tierBirthday(tier),
      avatar:'🦊', color:'#4ECDC4', voice:'woman', mascot:null,
      tierOverrides:{}, features, activitiesVisible:{}, youtube:[] };
    await context.addInitScript(([p, pages]) => {
      localStorage.setItem('vb_profiles', JSON.stringify([p]));
      localStorage.setItem('vb_active_id', p.id);
      if (pages.length) localStorage.setItem('vb_coloring_pages', JSON.stringify(pages));
      // capture audio INTENT without real audio
      window.__calls = [];
      for (const fn of ['speak','playSuccess','playBoop','playChime','playPop','haptic']) {
        const orig = window[fn];
        window[fn] = (...a) => { window.__calls.push({fn, args:a}); try { return orig && orig(...a); } catch {} };
      }
      window.addEventListener('error', e => (window.__errs = window.__errs||[]).push(String(e.message)));
    }, [profile, coloringPages]);
  }
  export const callsSince = (page) => page.evaluate(() => { const c=window.__calls||[]; window.__calls=[]; return c; });
  export const consoleErrors = (page) => page.evaluate(() => window.__errs||[]);
  export const VIEWPORTS = {
    phone:{width:390,height:844}, phoneLand:{width:844,height:390},
    tablet:{width:820,height:1180}, tabletLand:{width:1180,height:820},
  };
  ```
- [ ] **Step 2: Add the report collector** in `lib/harness.mjs`:
  ```js
  export function makeReport() {
    const rows = [];
    return {
      add(r){ rows.push({pass:true, severity:'-', ...r}); if(!r.pass) console.log('FAIL', r.id, r.detail||''); },
      rows: () => rows,
      summary(){ const f=rows.filter(r=>!r.pass); return {total:rows.length, failed:f.length, fails:f}; },
    };
  }
  export async function shot(page, name){ await page.screenshot({ path:`tests/e2e/v2/screenshots/${name}.png` }); return name; }
  ```
